# Podcast brief для Даши

Отдельный Render Web Service: принимает публичную ссылку на выпуск, получает аудио через `yt-dlp`, расшифровывает его через OpenAI и выдаёт персональный brief.

## Запуск на Render

1. Создай новый пустой GitHub-репозиторий `podcast-agent` и загрузи туда содержимое этой папки.
2. В Render создай **New → Web Service**, выбери репозиторий.
3. Укажи Build Command: `pip install -r requirements.txt`; Start Command Render прочитает из `Procfile`.
4. Добавь Environment Variable `OPENAI_API_KEY` (секретный ключ, не коммитить).
5. После deploy открой адрес сервиса, вставь ссылку и дождись brief.

## Ограничения первого релиза

- Работает с публичными ссылками, которые `yt-dlp` или прямая ссылка на аудио позволяют скачать.
- Длинные эпизоды могут упереться в лимит размера одного файла у API. Тогда следующий патч — автоматическое нарезание звука на части; не нужно менять архитектуру.
- Не хранит аудио и расшифровки после завершения запроса.
